# 功能要求

## 总览

- 语音业务始终优先，低延迟语音是首要产品设计目标。
- Bork 设计面向已知联系人、团队和临时群组。
- Bork 禁止使用固定中央服务器、托管 SFU 或服务端混音，也不得依赖任何固定中央服务。
- 不提供账户、好友、云同步、管理员或成员撤销功能
- 将 20 至 50 人作为房间规模设计目标，但不作绝对承诺和约束。
- Bork 不提供无头中继模式；需要桥接和群组转发时，自动使用 GUI Peer。
- Windows 开发、测试和正式版本均以单个 `bork.exe` 交付，无需安装器、配套 ZIP、额外下载的 DLL 或其他文件；没有版本例外。Microsoft Store 当前不是分发目标，不要求 MSIX。
- 单文件交付允许运行时为系统使用释放内嵌的驱动、DLL 和独立 helper。其他平台使用各自原生交付格式，不要求 macOS/Linux 使用 `.exe`。
- 当前贡献者测试 EXE 未签名，内嵌的 NetFilter demo 驱动保留发布者原始签名，不修改签名或绕过 Windows 驱动签名检查。demo 仅获准用于贡献者测试；单文件格式不授予生产 SDK 许可，正式分发仍需单独取得许可并审查。
- 构建、测试和 CI 不运行提权 helper，也不安装或启动驱动；CI 成功不代表真实 WFP 拦截或原生安装流程已通过验收。

## 创建和加入房间

- 作为房间创建者，我可以输入房间名称，并立即获得可复制的邀请。
- 作为受邀成员，我可以粘贴邀请加入房间。

## 群组音频与成员状态

- 作为房间成员，我可以进行低延迟群组语音通话。
- 作为房间成员，我可以设置昵称，并分别控制采集静音和播放静音。
- 作为房间成员，我可以使用默认按键 `` ` `` 或自定义单键进行全局按键说话；系统监听仅在房间内注册。
- 作为房间成员，我可以在成员列表中看到谁正在发言。
- 作为房间成员，我可以分别关闭默认开启的 AEC 和 RNNoise。

## 文件传输

- 作为发送方，我可以向已认证成员发送文件提议。
- 作为接收方，我可以选择保存位置，并在接受提议后开始接收文件。

## 屏幕共享

- 作为房间成员，我可以共享或观看其他成员的屏幕。

## Windows 游戏代理

- 整个功能由 `game_proxy` build tag 显式启用；默认版本不包含代理实现、iWAN/gVisor 依赖、驱动 helper、代理 Wails 接口和模型、设置页、底栏或样式，不以运行时隐藏代替编译隔离。
- 默认版本首次创建的配置只包含网络设置；读取启用版本的既有配置并保存网络设置时保留磁盘上最新的 `game_proxy` 数据，避免切换构建模式丢失节点或凭据。以下代理行为仅适用于启用版本。
- 主界面声明 `asInvoker`，不主动请求提权，正常启动时保持普通用户权限。Start 先以普通权限探测 Bork 专用 `bork_netfilter_demo` 服务；首次缺失时自动通过独立 helper 请求 UAC 授权并安装、启动内嵌原始签名 demo 驱动，已停止时校验后请求授权启动，已运行时直接使用；通用初始化错误不能触发盲目提权。
- 提权安装不得重启主应用或主动断开语音，不承诺 UAC 安全桌面期间全局按键说话仍可用。拒绝或取消 UAC 不退出 Bork，停止代理后迟到的授权不得恢复已取消的启动；安装一旦开始，取消可能留下已安装或运行的驱动，普通 Stop 不停止或卸载系统驱动。
- 驱动使用唯一服务名 `bork_netfilter_demo`，安装路径为 `%WINDIR%\System32\drivers\bork_netfilter_demo.sys`，DLL 使用受保护的 `%WINDIR%\System32\bork-netfilter-demo` 目录。helper 不读取用户节点配置或凭据；无旧用户迁移需求，不接管或删除旧的手工 `netfilter2` 安装。
- 设置的游戏代理页提供“导出 NetFilter 许可”按钮：从内嵌原始 RTF 获取内容，仅在用户点击时由浏览器 Blob 保存到本机，不自动生成配套许可文件。按钮与停止按钮同行，悬停提示完整名称和 RTF 格式；界面不显示内嵌 demo 或首次启动说明，许可本身及生产授权要求不变。
- 作为 Windows 用户，我可以配置一个或多个游戏目录；Bork 递归扫描各目录中的可执行文件，去重后仅代理匹配的完整路径。停止启动中的代理会取消目录扫描，不必等待全部目录扫描完成；取消不发布部分规则。
- 游戏代理运行或重连期间可以增删目录并保存；Bork 原子重扫并更新原生拦截规则和用户态匹配规则，不重启 iWAN 连接。其他节点参数在停止代理前不可修改，启动和停止过程中不接受设置保存。扫描、保存和驱动操作不得阻塞语音静音；保存失败且旧规则无法恢复时停止代理。
- 游戏代理首次连接或认证必须在明确超时后进入失败状态；仅已成功运行的连接在断线后自动重连。
- 游戏代理服务器当前仅通过 IPv4 UDP 连接；服务器字段可以填写 IPv4 地址或可解析出 A 记录的主机名。
- 游戏代理仅拦截 IPv4 TCP/UDP，DNS 必须是 IPv4；IPv6 endpoint 和 IPv4 回环 TCP 连接退出用户态过滤，不进入代理链路。
- 游戏代理 MTU 配置范围为 68 至 1600 字节，保证满足 IPv4 协议栈的最小 MTU。
- 单个 TCP/UDP endpoint 失败时只终止该 endpoint 并记录错误，不停止拦截 Bridge、iWAN 连接或其他代理流。
- 游戏代理界面显示有界且脱敏的连接事件日志，包括扫描、连接、认证、驱动、运行、断线、重试和错误，不显示密码或完整凭据。
- 连接日志支持按 `fatal`、`error`、`warning`、`info` 等级过滤，默认显示 `fatal`，并可将全部有界事件导出到本机日志文件。
- “全部”连接日志为每个 TCP 连接记录代理请求、首个入站数据和完成状态。通用 UDP 使用稳定 `flow_id` 记录方向明确的首个出站、首个入站、每 5 秒最多一次的流量聚合和完成状态，不推断请求与响应关系；DNS 使用 transaction ID 和稳定 `request_id` 关联请求与响应。日志包含地址、包数和字节数但不记录载荷或凭据；诊断队列过载时记录明确的丢弃计数。
- “全部”连接日志在 iWAN generation 建立、结束及 malformed、invalid IPv4、ICMP unreachable 等异常计数变化时记录分代累计数据路径快照；正常传输期间计数变化时每 10 秒最多记录一次。快照区分用户态协议栈出站、成功写入 iWAN 节点、从节点收到数据和成功注入协议栈的包数与字节数；入站单列 TCP、UDP、ICMP 和其他协议包数，并统计 ICMP destination-unreachable 与 port-unreachable，但不记录载荷或 ICMP 引用的原始报文。
- 主界面底栏每秒显示代理载荷的实时上行、下行速率；配置页不再重复显示“实时流量”或“本次运行目录”，保留可编辑的游戏目录、运行状态、错误和日志。
- 未加速且已保存有效节点时，主界面和语音界面底部显示“开始加速”，直接使用已保存配置，不读取设置草稿；缺少游戏目录时禁用并提示先添加目录。连接、运行或重连时提供“停止加速”，停止中禁用重复操作；启停请求不占用语音控件的忙碌状态，不停止语音或卸载驱动。
- 开始加速后，底栏显示连接状态、实时上下行速率、节点往返延迟及探测丢包；重连和停止期间速率归零，尚无延迟/丢包测量时显示未知而不是零。失败时保留明确标记为已停止更新的历史并允许重新开始，停止后收起图表，配置有效时保留开始入口；屏幕观看全屏时隐藏，不影响后台测量。
- 底栏连接状态只在“游戏加速”前以绿点（已连接）或红点（未连接）表示，不另显示“已连接”或节点连接文字，不显示底部常驻采样说明，为启停按钮留出空间。详细状态通过悬停和屏幕阅读器提供，指标定义保留在标题悬停提示中；缺少目录和失败后曲线冻结的必要提示仍显示。
- 延迟与探测丢包使用现有 iWAN ECHO，每 2 秒一次，2 秒内未匹配应答记为超时。延迟使用本机单调时钟；丢包为本次连接代次最近 30 秒内已完成探测的超时比例，不包括仍在等待、取消前未到期的探测或本地发送失败，不代表游戏服务器延迟或游戏数据包丢失。
- 上行、下行、延迟、丢包各展示最近 3 分钟曲线，共用后端时间轴；后端保留有界内存历史，速率每秒采样且最多 180 个点，关闭设置或切换房间不丢失，重连保留历史但不跨代连线，新一次手动启动清空。有效空闲速率绘为零；重连、延迟超时和未采样区间留白，不插值伪造数据。速率与延迟标明自适应量程，丢包量程固定为 0 至 100%，每个丢包历史点显示当时最近 30 秒的比例。
- 游戏代理配置使用 `game_proxy.directories` 列表，不支持旧的单值 `game_proxy.directory` 字段。
- 保存游戏代理配置时保留配置文件中最新的网络设置；停止操作同时取消尚未被运行时接收的启动请求。
- 游戏代理可以请求 iWAN XOR 数据混淆，默认关闭，最终数据模式使用服务器 `OPENACK` 返回的协商结果。
- 节点配置支持导入和导出标准 Base64 编码的 UTF-8 JSON，仅包含节点字段，不包含游戏目录或其他本机设置。导出将已保存节点复制到系统剪贴板；有未保存更改时须先保存。导入校验成功后只替换表单中的节点字段，保留目录，仍需显式保存，不自动启动代理；运行期间不可导入。界面须说明内容包含用户名和密码、Base64 并非加密，错误不回显导入内容。
- 服务器配置默认收起，点击“配置服务器”才展示节点字段和导入导出。保存成功或导入成功后收起，失败时保留草稿；导入后仍需显式保存，收起状态下也须显示未保存提示和保存入口。游戏目录、启动、停止和运行状态不随配置折叠。
- “配置服务器”与“添加目录”按钮放在同一行；保存、启停及许可导出集中在操作区，窄窗口换行时停止与许可导出仍保持同行。
